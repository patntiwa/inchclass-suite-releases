# Inch.Class Suite — distribution

Ce dépôt ne contient aucun code source. Il héberge uniquement les versions publiées
du plugin WordPress **Inch.Class Suite** (fichier zip) et leur manifeste signé, que le
plugin consulte pour proposer les mises à jour dans l'administration WordPress.

- Chaque version est signée (Ed25519) ; le plugin refuse tout paquet dont la signature
  ou l'empreinte ne correspond pas.
- La mise à jour n'est installable que sur un site dont la maintenance est à jour.
